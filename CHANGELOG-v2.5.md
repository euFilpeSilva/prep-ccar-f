# CCAR-F Study — v2.5 UX

## Objetivo
Melhorar a página inicial para atender usuários com diferentes níveis de inglês sem tornar o English Breakdown obrigatório.

## Alterações
- Página inicial passa a apresentar duas trilhas complementares:
  - Estudo técnico: Flashcards → Cenários → Simulador.
  - Inglês técnico: English Breakdown → Estruturas → Hoje → Exam Mode.
- Opção "Não tenho certeza" abre o guia na seção de diagnóstico.
- Adicionado "Continuar de onde parei", persistindo a última trilha no navegador.
- Cliques nas ferramentas principais passam a registrar a última atividade.
- English Breakdown é explicitamente tratado como módulo opcional de apoio ao inglês técnico.
- Mantido o acesso direto a todas as ferramentas.
- Texto de conclusão dos cenários atualizado para abranger os 5 domínios.
- Mantido o conteúdo dos 8 cenários da versão anterior.

## Observação
O conteúdo do aplicativo continua sendo material de treinamento autoral baseado nos conceitos da preparação; não é apresentado como reprodução de questões oficiais da certificação.
